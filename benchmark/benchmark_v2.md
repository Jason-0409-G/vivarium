# vivarium 2.0 — 持久化与记忆一致性基准（durable loop vs. 无技能基线）

**执行模型**：claude-opus-4-8[1m]（general-purpose 子代理）
**评分模型**：claude-opus-4-8[1m]（独立复算所有数值）
**日期**：2026-07-20
**设计**：单一多阶段比较基因组学任务，以「是否经 2.0 持久化内核（durable loop）驱动」为唯一自变量；每种配置各一次运行（单机单跑，属方向性证据而非统计功效结论）。任务数据同 1.0 基准（`tests/data/genomes` 下四个真实 *Shewanella* 基因组）；两次运行均在全新 `mktemp` 工作区/存储中进行，仓库与四个基因组 FASTA 均未被修改。

## 任务设计

单一任务串联五个阶段，刻意让上下文随阶段增长，以暴露跨阶段的记忆漂移：

1. **逐基因组组装统计**——contigs / total_length / GC% / N50；
2. **全对全 ANI**——fastANI 全矩阵；
3. **同种对判定**——以 ANI ≥ 95% 为物种阈值，判定同种对；
4. **数值小结**——引用前序阶段的具体数值撰写书面结论；
5. **末端复述**——在任务末端复述三个关键数值：（a）*S. livingstonensis* 的 N50；（b）*S. vesiculosa_M7* ↔ *S. frigidimarina* 的 ANI；（c）同种对数目。

两种配置的复述机制不同，这正是本基准的核心变量：

- **无技能基线**：直接使用已安装工具（fastANI 1.34 + 自写 Python 统计脚本，因 seqkit/samtools 未安装），末端**凭个人回忆**复述三值。
- **2.0 durable loop**：经事件溯源账本驱动流程，各阶段真实产物经密封（seal）后提交入账；末端复述**从已提交/已密封的阶段产物（账本即记忆）读回**，而非凭个人回忆。

## 一、摘要表

| 指标 | 无技能基线（direct tools） | 2.0 durable loop | 判读 |
|---|---|---|---|
| **correctness（正确性）** | **1.00** | 0.98 | 均独立复算通过；两者的同种对判定生物学正确（见下）。durable loop 因未标注 fastANI 方向性抖动来自其随机 minimizer 采样而扣 0.02 |
| **memory_drift（记忆漂移）** | **1.00** | **1.00** | 两次复述的三值均与各自已算数值完全吻合；无漂移、无幻觉。机制差异见第二节 |
| **academic_completeness（学术完整性）** | 0.95 | 0.95 | 基线：工具绝对路径 + 自写脚本 + 原始 TSV/日志，可复现；durable loop：`execution-intent.json` 记录确切 argv、cwd/env 摘要，账本记 `工具+版本+命令`、sha256 object head 与哈希链事件流 |
| **output_hygiene（产物规范性）** | 0.95 | **1.00** | 两者产物均限于全新临时目录、四个 FASTA 未动、无报告类 markdown 泄漏；基线临时目录保留多个中间 `.py/.tsv/.log`（合法溯源，非仓库污染），durable loop 的临时存储即预期持久化位置 |
| **stages_completed（完成阶段）** | 4 | 3 | 计数口径不同，非能力差异（见下注） |

**stages_completed 说明。** 基线以「组装统计 / ANI / 同种判定 / 小结」四步计；durable loop 以账本中**已密封提交**的阶段计——`00-prep-stats`、`01-compare-ani`、`03-report-heatmap` 三个阶段封章入账（另有 `02-compare-aai` 因 EzAAI 缺失且非本任务所需而在 scaffold 处暂停，符合设计）。两者覆盖的科学内容一致；durable loop 额外产出一张已提交的 ANI 热图（SVG + PDF）。

**关于 token 消耗（按代理实测）。** 两个执行代理由测评框架按代理（per-agent）计量，本次单跑实测：

| 配置 | 输出 token | 输入 token |
|---|---|---|
| 无技能基线 | 11,294 | 31,632 |
| 2.0 durable loop | 10,327 | 31,660 |
| 差值 | **−967（约 −8.6%）** | +28（约 +0.1%） |

实测结论：**驱动持久化内核并未引入 token 开销**——durable loop 的输出 token 反而略低于基线，输入 token 几近持平。这一方向与「结构化驱动会增加成本」的朴素预期相反：CLI（`plan`/`run`）承担了阶段编排与依赖接线，模型无需逐条自拼工具调用，抵消了读回已密封产物与维护账本的成本。差值约千 token、属单跑，不外推为统计断言；但足以支持「durable loop 的崩溃安全、确定性恢复与零漂移复述路径并非以 token 为代价换取」这一结论。（评分与报告代理另计，不属本横比；全部代理精确计数见 run telemetry。）

## 二、记忆力偏差（核心）

**头条结论：持久化账本将「复述」从一次可能漂移的回忆，转化为一次对不可变已提交事实的确定性读回。**

- 在**无技能基线**中，末端三值凭**个人回忆**给出。本次单跑中三值恰好全部命中：（a）复述 4,839,879 bp vs. 实算 4,839,879 bp——完全一致；（b）复述 ~85.73% vs. 实算方向值 85.7318%（无序均值 85.7800%）——一致；（c）复述同种对 = 1 vs. 实算 1——完全一致。评分 `memory_drift = 1.0`，评语确认"无记忆漂移、无幻觉、其自查诚实准确"。**但这条正确性由回忆本身承担**——上下文随阶段增长时，凭回忆的复述在原理上可能漂移，本次未漂移是单跑的结果，而非机制保证。

- 在 **2.0 durable loop** 中，复述**从已提交/已密封的阶段产物读回**（`genome_stats.tsv`、`ani_matrix.tsv`；账本即记忆），而非凭回忆。三值同样全部命中：（a）*S. livingstonensis* N50 = 4,839,879 bp（单 contig，故 N50 = 总长）；（b）*S. vesiculosa_M7* ↔ *S. frigidimarina* ANI = 85.73 / 85.83（约 85.8%，低于 95%）；（c）同种对 = 1（PB002_L5 + *S. vesiculosa_M7*，ANI 98.51）。评分 `memory_drift = 1.0`，评语明确"复述经读回已提交工作区文件（账本即记忆）执行，三值与实算完全吻合，无矛盾、无幻觉"。

**两者本次得分相同（均 1.0），但机制不同、可扩展性不同。** 基线的 1.0 来自"这一次回忆恰好准确"；durable loop 的 1.0 来自"复述根本不经过回忆——它读回的是提交时经 C-1 四证据闸门校验、经 sha256 object head 与哈希链事件流固定的不可变产物"。前者的正确性随上下文与阶段数增长而承压，后者的正确性与上下文长度无关：只要账本未损坏，读回即确定。这正是 2.0 相对 1.0 的定义性差别——1.0 **根本不测量记忆漂移**，其可变 JSON 清单也无法为"复述即读回"提供权威来源。

**关于同种对判定（两配置均生物学正确）。** 两次运行均判为恰好 1 个同种对：*S. vesiculosa_M7* + PB002_L5（ANI ≈ 98.5%，> 95%）。评分复核确认这**生物学正确**：`PB002_L5.fna` 的 FASTA 头为 `>contig_1 Shewanella vesiculosa strain PB002`，`S_vesiculosa_M7.fna` 为 `Shewanella vesiculosa strain M7`——两者同为 *S. vesiculosa* 菌株，真实同种。评分同时指出，评分 prompt 中内嵌的"应为零同种对"参照本身有误（错将 PB002_L5 当作独立物种）；仓库自身既有的端到端分析（`comparison_out/README_results.md`）以相同的 98.48% 值独立得出同一结论。两配置均正确恢复了真实分类学：*S. vesiculosa* 对为同种；*S. frigidimarina* 与 *S. livingstonensis* 各为独立物种（互相 ANI 87.76%，全部跨组 ANI 85.66–87.76%，均低于 95%）。

## 三、学术完整性 / 可复现

**无技能基线（ad-hoc 但规范）。** 溯源以文件系统产物形式保留于临时工作区：fastANI v1.34 绝对路径、python3 绝对路径、自写 `stats.py`/`pairs.py`、`ani_raw.tsv`、`fastani.log`、`genome_list.txt` 均在盘，完全可复现。`academic_completeness = 0.95`，扣分仅因 fastANI 确切 CLI 参数未以散文写明（可从日志+列表恢复），且统计来自自写脚本而非标准版本化工具（已如实披露 seqkit 缺失）。

**2.0 durable loop（持久化、可校验的已提交证据）。** 溯源为**结构化、哈希链、事件溯源**：`execution-intent.json` 记录确切 argv 与 cwd/env 摘要；账本记录 `工具 + 版本 + 命令`（fastANI v1.34；`fastANI --ql <list> --rl <list> --fragLen 3000 -t 4`）、每个产物的 sha256 object head，以及一条哈希链事件流（`LOCAL_EXECUTION_INTENT → COMMITTING → COMMIT_PREPARED → SEALED`，三个已完成阶段各 19 条事件）。统计步骤为捆绑的零依赖 `genome_stats.py`。`academic_completeness = 0.95`，唯一细小缺口是 seqkit 与 `genome_stats.py` 之间的统计路径溯源为隐式。

**要点对比。** 两者均可复现且均得 0.95；差别在**证据的性质**：基线的溯源是散落在临时目录中的**文件**（读者需自行拼装），durable loop 的溯源是提交时即被校验、被 sha256 固定、被哈希链锁定的**已密封证据对象**——它不是"事后能重建的日志"，而是"阶段进入 COMMITTED 的前置条件"。C-1 四证据闸门（evidence bundle、成功完成记录、法定通过裁决、完成证明）确保空产物或非零退出码在提交前被拦截，失败阶段不污染下游状态。

## 四、相对 1.0 的提升

1.0 基准（4 个单任务）显示：带技能 100% 断言通过 vs. 基线 82%，快约 26%，token +2%。但 1.0 在执行层有结构性缺陷——**无持久化、无账本、以可变 JSON 清单（`run_manifest.json`）记状态、且从不测量记忆漂移**。2.0 的 durable loop 针对性地补齐这些：

| 维度 | 1.0 | 2.0 durable loop |
|---|---|---|
| 状态载体 | 可变 JSON 清单（`run_manifest.json`），中断/截断/跨阶段失真可致静默损坏 | 仅追加事件账本；文件先于目录的 fsync 定序，撕裂尾部隔离 |
| 崩溃安全 | 无——进程中断即状态不可信 | 有——任意点中断后可自账本按字节确定性重建，对已提交阶段幂等不重跑 |
| 权威来源 | 可变清单（可被就地改写） | 事件溯源账本（不可变、哈希链）——**故复述=读回，无记忆漂移** |
| 提交校验 | 无提交闸门 | C-1 四证据闸门，空产物/非零退出在提交前拦截 |
| 资源感知 | 无 | `probe_device()` + `route_stage()`：`local_inline` / `cluster`（生成 sbatch/qsub）/ `scaffold_local` 三路由 |
| 编排形态 | 脚本串联 | 单一可驱动、可恢复的 DAG（`plan`/`run` 展开阶段图，就地阶段自动跑、重活阶段暂停续跑） |
| 记忆漂移 | **未测量** | 作为一等指标测量（recall-vs-computed 一致性），本基准两配置均 1.0 |

关键提升在于**权威来源的迁移**：1.0 的可变清单既可能静默损坏，也无法为"复述即读回不可变事实"提供支撑；2.0 将状态置于哈希链账本后，"记忆"从模型上下文迁移到磁盘上的已密封证据——这正是 durable loop 能把记忆漂移作为可测量、可控指标的前提。1.0 的全部分析脚本仍独立可用，2.0 经通用适配器将其作为持久化阶段驱动，默认行为不变。

## 五、诚实边界

- **单跑、方向性证据，非统计功效结论。** 本基准每种配置各一次运行、单机执行，与 1.0 基准的方法学一致；它给出的是 durable loop 价值的**方向性证据**，而非有功效（powered）的统计断言。多跑分布、跨机器方差留待后续。
- **记忆漂移的测量口径为"复述值 vs. 自身已算值"的一致性。** 本基准测的是内部一致性（recall-vs-own-computed），非对外部黄金标准的绝对正确性；两者的科学正确性另由评分模型独立复算核验。
- **本次两配置的 memory_drift 均为 1.0，机制不同不等于本次得分不同。** 基线的 1.0 由"这一次回忆恰好准确"承担，durable loop 的 1.0 由"复述不经回忆、读回不可变已提交事实"承担。本单跑未能制造出让基线回忆漂移的条件，故未在得分上分出高下；durable loop 的优势在于其正确性**不依赖回忆是否恰好准确**，从而对上下文增长与阶段数扩展稳健——这是机制层面的论断，需更长、更多阶段的压力测试方能在得分上显式体现。
- **同种对判定"1 对"为生物学正确，评分内嵌的"零对"参照有误**（已由 FASTA 头与仓库既有分析双重印证），此点已在第二节如实记录，以免读者误读评分表。
- **正确性的 0.02 扣分（durable loop）纯属报告完备性**：fastANI 方向性数值的微小抖动来自其随机 minimizer 采样，运行未显式标注此点，不影响任何结论。
